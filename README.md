# Subba's Storybook

Create a premium, highly emotional, interactive OFFLINE birthday

experience website for my non-blood brother “Subba”.

IMPORTANT:

This is NOT a normal birthday website.

It should feel like a handcrafted digital birthday gift / interactive

memory book / cinematic story.

Use the attached reference design only as INSPIRATION.

Do NOT copy its exact layout, colors, typography, illustrations,

animations, or UI.

Take the strongest ideas from the reference and redesign everything

into a much more polished, unique, organized and emotionally immersive

experience.

The website must work completely OFFLINE.

No backend.

No database.

No external API.

No internet dependency.

All images, music, animations and content must work from local assets.

====================================================

CORE EXPERIENCE

====================================================

The entire website should feel like a JOURNEY.

The user should never feel like they are navigating a normal website.

Instead:

OPEN → DISCOVER → INTERACT → REMEMBER → READ → EXPLORE MEMORIES

→ EMOTIONAL MESSAGE → SURPRISE → FINAL BIRTHDAY WISH

Use smooth transitions between every chapter.

Do NOT create a cluttered dashboard.

Do NOT put all sections on one long page.

Do NOT make it look like a template.

Create an intentional visual hierarchy.

====================================================

VISUAL DIRECTION

====================================================

Overall mood:

• cinematic

• warm

• intimate

• nostalgic

• premium

• emotional

• playful in some moments

• elegant in emotional moments

Think:

“a luxury digital scrapbook + cinematic short film +

interactive Pinterest editorial + personal memory book”

Color direction:

Primary:

warm ivory / soft cream

Secondary:

deep burgundy / wine

Accent:

soft rose / dusty pink

Supporting:

warm gold

Dark sections:

deep charcoal / burgundy-black

Avoid excessive bright pink.

Use white space generously.

Use subtle paper textures, grain, soft glow,

handwritten details and elegant borders.

====================================================

TYPOGRAPHY

====================================================

Use a combination of:

Elegant serif for emotional headings.

Clean modern sans-serif for UI.

Handwritten/script font only for tiny personal notes.

Typography should feel editorial and premium.

Do NOT use too many fonts.

====================================================

OPENING EXPERIENCE

====================================================

Create a full-screen cinematic opening.

Dark / warm background.

Display:

“21 • 09”

Then slowly reveal:

“Today isn't just another day…”

Pause.

Then:

“It's YOUR day, Subba.”

Use subtle particles / floating light / film grain.

A small button:

“Open your surprise →”

When clicked, transition into the birthday experience.

====================================================

CHAPTER 01 — THE FIRST SURPRISE

====================================================

Create an interactive birthday scene.

Instead of simply showing balloons:

Place several floating balloons around the screen.

Each balloon has a subtle number / symbol.

The user clicks or taps balloons.

Each interaction triggers:

• tiny confetti

• sound effect

• micro-message

• gentle animation

After all required balloons are interacted with:

Reveal:

“Okay… now we're getting started.”

Then transition into the cake scene.

====================================================

CHAPTER 02 — MAKE A WISH

====================================================

Create a beautiful realistic-but-stylized birthday cake.

One candle in the center.

Text:

“Before you continue…”

“Make a wish.”

User interacts with the candle.

Allow:

• click

• hold

• microphone interaction ONLY if browser permission

is available

BUT microphone must NOT be required.

Provide a fallback button:

“Blow it out ✨”

When candle goes out:

screen briefly becomes dark.

Then glowing text appears:

“Some wishes are meant to come true.”

Transition into the next chapter.

====================================================

CHAPTER 03 — THE FLOWERS

====================================================

Create a premium rose bouquet reveal.

Instead of simply displaying a flower image,

animate the bouquet appearing gradually.

Petals subtly move.

Text:

“A little something for you…”

Then reveal several floating handwritten notes around the bouquet.

Examples:

“You are my sunshine.”

“Forever yours.”

“You make my world beautiful.”

“I'm lucky to have you.”

“Happy Birthday, Subba ❤️”

IMPORTANT:

Make these editable content objects so I can change the text later.

After interaction:

button:

“There's more…”

====================================================

CHAPTER 04 — A MESSAGE FROM MY HEART

====================================================

Create an elegant letter-opening interaction.

Show a sealed envelope centered on the screen.

Text:

“A message from my heart”

“Tap to open”

When clicked:

Envelope opens.

Letter card slides upward.

Use realistic paper movement.

The letter should feel handwritten / personal.

Do NOT put the entire letter immediately on screen.

Reveal the letter line-by-line or paragraph-by-paragraph.

Add subtle heart / paper animation.

Allow the letter to scroll naturally.

====================================================

CHAPTER 05 — OUR MEMORY TIMELINE

====================================================

THIS IS THE MOST IMPORTANT SECTION.

I have 50+ personal photos and potentially 100+ photos.

Do NOT display them as a boring gallery.

Create an interactive MEMORY TIMELINE.

Organize memories chronologically.

Each memory should contain:

• photo

• date

• place

• short title

• emotional caption

• longer story/message

Example:

2023

“Where it all started”

PHOTO

“Some moments don't look important

when they happen…”

Clicking the memory opens a cinematic memory card.

====================================================

PHOTO PRESENTATION

====================================================

Photos should appear in different editorial layouts.

Do NOT make every photo the same size.

Use:

• large hero photo

• Polaroid

• film strip

• scrapbook card

• tilted photograph

• overlapping photos

• full-screen photo

• 2-photo spread

• 3-photo collage

BUT maintain a consistent design system.

Do not randomly scatter photos.

Every layout must feel intentional.

====================================================

MEMORY INTERACTION

====================================================

When a photo is clicked:

Background becomes darker.

Photo expands into focus.

Other elements fade.

Show:

DATE

PLACE

TITLE

Then reveal the story.

Example:

“Remember this day?”

“Because I still do…”

Then the personal message appears.

Add subtle:

• zoom

• parallax

• film grain

• floating dust

• soft light leak

Provide:

← Previous Memory

Next Memory →

Do NOT make navigation confusing.

====================================================

MEMORY MAP / CHAPTER NAVIGATION

====================================================

Add a minimal floating chapter indicator.

Example:

01 INTRO

02 WISH

03 FLOWERS

04 LETTER

05 MEMORIES

06 US

07 FINAL SURPRISE

The indicator should remain subtle.

Do not use a traditional navbar.

====================================================

CHAPTER 06 — LITTLE THINGS ABOUT YOU

====================================================

Create an interactive section containing small personal notes.

Cards appear one by one.

Examples:

“Things I appreciate about you”

“Things you probably don't realize”

“Reasons you're special”

“Little memories I never want to forget”

Each card can be clicked.

Clicking opens a tiny emotional message.

Use elegant cards / handwritten notes.

====================================================

CHAPTER 07 — PHOTO WALL

====================================================

Create a visually stunning editorial photo wall.

Use 20–30 photos initially.

Organize them like a physical scrapbook.

Some photographs can overlap.

Some can be taped using visual tape.

Some can have tiny handwritten notes.

When hovered:

photo gently lifts.

When clicked:

open full-screen memory.

Do NOT use excessive hover animation.

Keep movement subtle.

====================================================

CHAPTER 08 — OUR LITTLE UNIVERSE

====================================================

Create something unique here.

Instead of another gallery:

Create a dark cinematic interactive space.

Tiny stars / glowing points represent memories.

Each glowing point represents one photo or moment.

Clicking a star opens:

PHOTO

DATE

MEMORY

MESSAGE

This should feel like:

“Our little universe.”

Make it beautiful but lightweight.

====================================================

CHAPTER 09 — ONE LAST THING

====================================================

Slow everything down.

Dark background.

Centered text:

“One last thing…”

Pause.

Then:

“I saved this one for the end.”

Show a gift box.

User clicks the box.

Box opens with a premium animation.

Inside:

the most meaningful photo / video / message.

Do NOT reveal it immediately.

Build anticipation.

====================================================

FINAL LETTER

====================================================

Create the final emotional section.

Full-screen warm background.

Heading:

“Dear Subba…”

Then display the final birthday message.

The letter should feel like a personal handwritten letter.

Use line-by-line reveal.

At the bottom:

“Happy Birthday, Subba ❤️”

Then:

“Thank you for being part of my life.”

Do not make the final section overly flashy.

The emotional message should be the focus.

====================================================

FINAL MEMORY

====================================================

Very slowly zoom in.

Text:

“Some people become memories.

Some people become home.”

“Happy Birthday ❤️”

====================================================

“Replay from beginning”

“Open memories”

The site must support a local background music file.

Start music after the first interaction.

Add a tiny elegant music control.

Use:

play / pause

====================================================

• balloon pop

Every sound must be optional and gracefully fail

RESPONSIVE DESIGN

====================================================

Desktop must feel cinematic.

Mobile must feel like a premium interactive birthday card.

Do NOT simply shrink the desktop UI.

Create responsive layouts intentionally.

For mobile:

• large touch targets

• vertical memory timeline

• swipe-friendly photos

• simplified animations

• no tiny text

====================================================

and mobile device.

====================================================

DESIGN PRINCIPLE

====================================================

The reference website is only a starting inspiration.

Create something SIGNIFICANTLY MORE UNIQUE.

The final result should feel like:

“I made an entire digital world just for you.”

Not:

“I built a birthday webpage.”

Every section should have a reason to exist.

Every transition should feel intentional.

Every photo should feel like part of the story.

Every message should feel personal.

Make the final experience emotional, cinematic,

beautiful, premium and memorable.

Do NOT use placeholder lorem ipsum.

Use realistic sample content only where necessary,

and clearly structure it so I can replace it with my actual

photos and messages later.

Before coding, first create the complete UI/UX architecture,

screen flow and component hierarchy based on this specification.

Then implement the website.
